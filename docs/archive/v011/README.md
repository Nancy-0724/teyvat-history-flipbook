# 《提瓦特通史》V0.11

一本書、八篇、六十章的翻頁電子書。目前五章正文草稿、55章綱要；不是完整出版終稿。

## 閱讀

解壓後開啟 `index.html`；瀏覽器限制直接開檔時，可在此資料夾執行 `python -m http.server 8000` 再讀取本機網站。目錄可搜尋章名、小節、正文與綱要；輸入「天使」「仙靈」「尼可」或「妮可」後點選小節結果，即可跳到第五章相關文字。StPageFlip 不可用時仍有 CSS 翻頁備援。沒有代為發布上線。

## 本版已修正

第五章加入天使／仙靈對照圖位與尼可人物圖位，附來源與圖說；圖 2-6 截止三月守望；圖蘭／三月／四影圖解固定保留；圖號不因載入改變；共用手機章首頁與卷首卷末分頁修正。所有原圖、核定正文及舊書籤保留。全書搜尋加入段落定位與「妮可／尼可」別名。

## 圖片的重要限制

**本包未內附第三方人物或遊戲圖片。**新增三張來源圖會在有網路時嘗試載入；下載失敗或離線時顯示明確提示卡，不是人物肖像。已核對來源不等於下載成功。只有執行下載並成功取得檔案後，人物圖才能離線閱讀。

Windows 可執行 `下載第五章配圖_連網後執行.bat`；或使用 `python tools/fetch_game_art.py --chapter 5`。重新開啟網站即可讀取成功保存的圖片。來源網站可能限制下載／熱連結；查看圖片時可開啟出處另行確認。公開素材不等於取得再散布授權。

## 建置

```bash
python tools/build.py
python tools/validate.py
python tools/prepare_site.py
```

`_site/` 為當前部署輸出，GitHub Pages 工作流程保留。生成 JS 不手改。最新交接：`docs/提瓦特通史_跨對話編纂交接_V0.11_2026-10-31.md`。
