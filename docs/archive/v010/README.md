# 《提瓦特通史》V0.10

一本書、八篇、六十章的靜態翻頁電子書。本版已收錄第一至第五章正文，其餘55章保留綱要；全部已寫章仍標 draft，未完成官方遊戲客戶端繁中終校。

## 閱讀

解壓後開啟 `index.html`，在目錄搜尋「人類」進入第五章。瀏覽器限制直接開檔時，可在本資料夾執行 `python -m http.server 8000` 再開啟本機網站。StPageFlip CDN可用時使用其翻頁；不能載入時保留CSS備援。沒有代為上線到任何帳號。

## 本版變更

第五章天使一節由五段收為三段，保留來歷、使命、仙靈關係及尼可與教導人類的簡例。其餘第五章正文及章末補充不改寫。第二、四章納入前次核定的去重與銜接修訂；第一、三及第六至六十章原文不變。

啟用既存圖5-1「世界改造與早期人類文明」；20張正文引用SVG可離線顯示。所有原有圖片資產與15組遊戲圖映射保留，第三方人物圖仍未封裝，本次沒有新增天使肖像。原固定章號、錨點與舊書籤保留，失效段落補上同主題定位。

## 建置與部署

```bash
python tools/build.py
python tools/validate.py
python tools/prepare_site.py
```

`_site/` 是當前可部署靜態輸出；`.github/workflows/pages.yml` 保留原GitHub Pages工作流程。完整來源、已編譯JS、史料末註與修訂紀錄均在ZIP內。生成的JS請勿手改。

## 驗證與限制

build／validate／prepare_site與JS語法通過。嵌入式Chromium桌面與手機模擬各38項通過；結果見 `docs/QA_V010.md`。測試使用原始HTML/CSS/JS、SVG data URI與記憶體儲存夾具，不等於真實CDN、Windows直接開檔、實體手機、磁碟儲存或網站發布驗收。
