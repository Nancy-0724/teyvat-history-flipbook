# 《提瓦特通史》V0.12

一本書、八篇、六十章。現有五章正文草稿、55章綱要。

## 閱讀與更新

解壓後開啟 `index.html`。更新既有專案時，把更新包解壓覆蓋到含有 `index.html` 的原資料夾，不必刪除舊資料夾；已下載的 `assets/game-media/` 圖片會保留。部署檔案位於 `_site/`。

## 本次修改

書頁只保留簡短圖號與圖名，不再重複顯示逐圖免責說明、連網狀態與點圖提示。第五章兩幅對照圖合用一行「圖 5-2｜天使（左）與仙靈（右）」。點圖後可查看來源；長說明預設收合。

60份章節Markdown、原SVG、來源網址及閱讀位置均保持不變。短圖說由 `data/figure-presentations.json` 管理；實際生成檔由建置工具產生，不手改。

## 圖片

沿用原有本機優先、連網載入的方式；本次未新增下載圖片。已有本機圖片可繼續使用。首次保存第五章來源圖可執行 `下載第五章配圖_連網後執行.bat`，或 `python tools/fetch_game_art.py --chapter 5`。
